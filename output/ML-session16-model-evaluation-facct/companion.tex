\section{Classifier Evaluation Metrics}
\secsub{Rigorously quantifying model performance across confusion matrix metrics, ROC-AUC, and regression loss.}

Selecting the right evaluation metric is essential. High accuracy can be deceiving on imbalanced datasets.

\subsection{Confusion Matrix Metrics}
\begin{align}
\text{Precision} &= \frac{TP}{TP + FP} \\
\text{Recall (Sensitivity)} &= \frac{TP}{TP + FN} \\
\text{F1-Score} &= 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}
\end{align}

\housefig{figures/fig_roc_auc.png}{Receiver Operating Characteristic (ROC) curve plotting TPR vs FPR with Area Under Curve (AUC).}

\begin{worked}{Medical Classification Metrics}
Consider a medical test on 100 patients: $TP=40, FP=10, FN=5, TN=45$.

\begin{steps}
\item \textbf{Accuracy:} $\frac{40+45}{100} = 85\%$.
\item \textbf{Precision:} $\frac{40}{40+10} = \frac{40}{50} = 80\%$.
\item \textbf{Recall:} $\frac{40}{40+5} = \frac{40}{45} = 88.9\%$.
\item \textbf{F1-Score:} $2 \cdot \frac{0.80 \times 0.889}{0.80 + 0.889} = 84.2\%$.
\end{steps}
\end{worked}

\section{Introduction to FAccT ML}
\secsub{Ensuring Fairness, Accountability, Transparency, Privacy, and Robustness in real-world AI systems.}

Beyond raw predictive accuracy, deployment of machine learning models in high-stakes domains (healthcare, hiring, judicial sentencing) requires adherence to \textbf{FAccT} principles:
\begin{itemize}[leftmargin=*]
    \item \textbf{Fairness:} Preventing discrimination against protected groups (gender, ethnicity).
    \item \textbf{Accountability:} Identifying who takes responsibility when automated decisions fail.
    \item \textbf{Transparency \& Interpretability:} Explaining how decisions are made.
    \item \textbf{Privacy \& Security:} Protecting sensitive user data against leakage and adversarial attacks.
\end{itemize}

\section{Algorithmic Bias \& Fairness Through Unawareness}
\secsub{Why simply excluding sensitive attributes fails to eliminate systemic algorithmic bias.}

A famous real-world example is the COMPAS risk assessment tool used in judicial bail decisions. Analysis revealed that black defendants were misclassified as high risk (false positive) at twice the rate of white defendants.

\subsection{The Fallacy of Fairness Through Unawareness}
A common misconception is that removing protected features (such as race or gender) guarantees a fair model.

\begin{watchout}
\textbf{Redundant Encoding:} Non-sensitive features (zip code, income, education level) are often strongly correlated with protected attributes. ML models implicitly reconstruct protected attributes from proxy features.
\end{watchout}

\section{Interpretability vs Performance Trade-Off}
\secsub{Balancing predictive accuracy against model transparency across machine learning families.}

\housefig{figures/fig_tradeoff_facct.png}{Trade-off between predictive accuracy and model interpretability across ML model families.}

Simple models like Decision Trees and Linear Regression provide built-in feature attribution coefficients but may lack capacity for complex patterns. Machine Learning provide superior performance but function as black boxes.

\section{Summary \& Self-Test}
\begin{keytake}
Evaluation requires going beyond accuracy to include Precision, Recall, and ROC-AUC. FAccT ML ensures models are fair, accountable, transparent, and secure. Removing protected attributes does not prevent bias due to proxy feature correlations.
\end{keytake}

\subsection{Self-Test Quiz}
\textbf{Q1:} Why is "Fairness Through Unawareness" ineffective?

\flipanswer{Because correlated proxy features allow models to implicitly reconstruct sensitive attributes.}
