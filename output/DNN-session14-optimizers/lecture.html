Optimizers in Deep Learning

Session 14 Interactive Lecture · Work Integrated Learning Programmes, BITS Pilani

1. Optimization Overview

Optimization algorithms update parameter weights along the gradient of the loss function $f(w)$. Standard Gradient Descent uses fixed learning rates, whereas adaptive methods scale step sizes dynamically.

3. Step-by-Step Benchmark

All six algorithms start at $x_0 = 4.0$ on $f(x) = x^2$ with $\eta = 0.1$. Below are the resulting locations after 3 steps:

  • GD: $x_3 = 2.048$
  • Momentum ($\beta=0.9$): $x_3 = 0.248$ (fastest convergence)
  • NAG ($\beta=0.9$): $x_3 = 0.712$
  • Adagrad: $x_3 = 3.774$ (decaying step sizes)
  • RMSProp ($\beta=0.9$): $x_3 = 3.284$
  • Adam ($\beta_1=0.9, \beta_2=0.999$): $x_3 = 3.700$

4. Comparison & Selection

Use Adam as your starting optimizer in general deep learning tasks ($\eta \approx 10^{-3} \dots 3 \times 10^{-4}$). For vision architectures, SGD with momentum often yields higher test performance when carefully tuned.
