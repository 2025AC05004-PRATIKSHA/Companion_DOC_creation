01 · Receptive Field Expansion

Dilated (Atrous) Convolutions

Dilated convolutions insert spaces (rate \(r\)) between kernel elements to expand receptive field size without adding parameters.

$$ \text{Effective Kernel Size } K' = K + (K-1)(r-1) $$

⚡ Dilated Kernel Rate Visualizer

Slide dilation rate \(r\) to see how a $3 \times 3$ kernel expands its spatial reach over a $7 \times 7$ feature map.

02 · Spatial Dimension Calculations

Interactive Output Dimension Calculator

Solve spatial dimension problems for convolution and pooling operations step-by-step.

$$ O = \left\lfloor \frac{N + 2P - K}{S} \right\rfloor + 1 $$

⚡ Slide 29 Problem Solver

Adjust input size \(N\), kernel size \(K\), padding \(P\), and stride \(S\) to compute exact output feature map shape.

03 · Architectural Efficiency

Bottleneck Blocks (ResNet)

Bottleneck blocks use $1 \times 1$ convolutions to squeeze channel dimensions before expensive $3 \times 3$ convolutions, achieving massive parameter reductions.

⚡ Bottleneck Parameter Comparison Lab

Compare parameters between a standard 256-channel $3 \times 3$ convolution and a 3-layer Bottleneck Block.

04 · Parameter Counting

Complete CNN Parameter Calculator

Calculate parameters across Convolutional, Pooling, and Dense layers.

$$ \text{Params}_{\text{Conv}} = (K \times K \times C_{\text{in}} + 1) \times C_{\text{out}}, \quad \text{Params}_{\text{Pool}} = 0 $$

⚡ Conv Layer Parameter Explorer

Adjust kernel size \(K\), input channels \(C_{\text{in}}\), and filter count \(C_{\text{out}}\) to inspect exact parameter counts.

05 · Wrap Up

Key Takeaways

1 · Dilated Convolutions

Expand receptive field exponentially without downsampling spatial resolution or adding parameters.

2 · Bottleneck Efficiency

$1 \times 1$ convolutions reduce channel depth before $3 \times 3$ convs, achieving $8.5 \times$ parameter savings.

3 · Skip Connections

Residual identity shortcuts enable stable gradient propagation across 100+ layer networks.
