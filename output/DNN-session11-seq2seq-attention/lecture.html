Session 11: Seq2Seq & Attention Mechanisms

Mastering Encoder-Decoder bottlenecks, soft sequence alignment, and dynamic context calculation.

1. The Seq2Seq Bottleneck Problem

Traditional sequence-to-sequence models squeeze an entire input sentence into one fixed context vector $c$. Long sentences suffer from severe information loss.

2. The Attention Mechanism

Attention creates a dynamic context vector $c_i$ for each decoder step $i$ by taking a weighted sum over all encoder hidden states $h_j$:

$$c_i = \sum_{j=1}^{T} \alpha_{ij} h_j$$

3. Attention Math & Scores

Alignment scores $e_{ij}$ evaluate how well decoder state $s_{i-1}$ matches encoder state $h_j$. Softmax turns raw scores into probability weights $\alpha_{ij}$.

Attention Variant Alignment Score Equation
Bahdanau (Additive) $e_{ij} = v_a^T \tanh(W_a s_{i-1} + U_a h_j)$
Luong (Multiplicative) $e_{ij} = s_{i-1}^T W_a h_j$
Dot Product $e_{ij} = s_{i-1}^T h_j$

4. Worked Numerical & Self-Test

Fully Worked Attention Example

Given encoder states $h_1 = [1,0]^T, h_2 = [0,2]^T, h_3 = [1,1]^T$ and decoder state $s = [2,1]^T$:

  • Dot Scores: $e_1 = 2.0, e_2 = 2.0, e_3 = 3.0$
  • Softmax Weights: $\alpha_1 \approx 0.2119, \alpha_2 \approx 0.2119, \alpha_3 \approx 0.5761$
  • Context Vector: $c = 0.2119 h_1 + 0.2119 h_2 + 0.5761 h_3 = [0.7880, 0.9999]^T$
