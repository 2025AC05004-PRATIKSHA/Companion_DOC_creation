01 · Learning Paradigms

Lazy vs Eager Learning

Lazy learning (k-NN) stores training examples without model training, deferring computation to query time. Eager learning builds global models eagerly.

02 · Vector Metrics

Minkowski Distance Metrics

$$ L_p(\mathbf{x}, \mathbf{y}) = \left( \sum_{i=1}^d |x_i - y_i|^p \right)^{1/p} $$

Manhattan ($p=1$), Euclidean ($p=2$), Chebyshev ($p=\infty$).

Feature Scaling & Curse of Dimensionality

Min-Max scaling and Z-score standardization ensure features with large magnitudes do not dominate distance calculations.

05 · Summary

Key Takeaways

  • k-NN classifies by majority vote over k nearest stored instances.
  • Distance metric choice (L1 vs L2) shapes neighborhood geometry.
  • Feature scaling is essential for distance-based methods.
