01 · Probabilistic Updating

Bayes' Theorem

$$ P(h \mid D) = \frac{P(D \mid h) P(h)}{P(D)} $$

Updates prior parameter beliefs $P(h)$ using observed data likelihood $P(D \mid h)$ to form the posterior distribution $P(h \mid D)$.

02 · Parameter Estimation

MAP vs Maximum Likelihood Estimation

MAP includes prior beliefs $P(h)$. Under a uniform prior, MAP simplifies to MLE: $\arg\max_h P(D \mid h)$.

04 · Loss Derivations

Deriving Loss Functions from MLE

Minimizing Sum-of-Squares Error (SSE) directly maximizes log-likelihood under zero-mean Gaussian noise $\mathcal{N}(0, \sigma^2)$.

05 · Summary

Key Takeaways

  • Posterior = Prior x Likelihood / Evidence.
  • MLE finds parameters maximizing observed data probability.
  • Squared error loss is equivalent to Gaussian log-likelihood maximization.
