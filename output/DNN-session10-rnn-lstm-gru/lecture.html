1. Why Sequence Models?

Standard feedforward neural networks assume every sample is independent. However, real-world data like sentences, stock prices, audio, and videos depend on order.

Everyday Analogy: Conveyor Belt Inspector

If an inspector treats every item independently, they miss contextual cues. If item 7 is slightly damaged, item 8 is very likely defective! A sequence model keeps memory of item 7 while inspecting item 8.

2. Vanilla RNN Architecture

Recurrent Neural Networks pass a hidden state vector $h_t$ across time. At each step $t$, the network reuses the exact same weight matrices $W_{hx}, W_{hh}, W_{yh}$.

The mathematical formulation for the forward pass is:

$$h_t = \tanh(W_{hx} x_t + W_{hh} h_{t-1} + b_h)$$ $$\hat{y}_t = \text{softmax}(W_{yh} h_t + b_y)$$

3. BPTT & Vanishing Gradients

Backpropagation Through Time (BPTT) unrolls the graph backwards across timesteps. Multiplying activation derivatives and weight matrices repeatedly causes exponential decay.

$$\frac{\partial L_T}{\partial h_k} = \frac{\partial L_T}{\partial h_T} \prod_{j=k+1}^{T} \frac{\partial h_j}{\partial h_{j-1}}$$

4. Long Short-Term Memory (LSTM)

LSTMs prevent vanishing gradients by using an additive Cell State highway $C_t$ controlled by three multiplicative gates:

  • Forget Gate: $f_t = \sigma(W_f x_t + U_f h_{t-1} + b_f)$
  • Input Gate: $i_t = \sigma(W_i x_t + U_i h_{t-1} + b_i)$
  • Candidate State: $\tilde{C}_t = \tanh(W_c x_t + U_c h_{t-1} + b_c)$
  • Cell State Update: $C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$
  • Output Gate: $o_t = \sigma(W_o x_t + U_o h_{t-1} + b_o)$
  • Hidden State: $h_t = o_t \odot \tanh(C_t)$

5. Gated Recurrent Units (GRU)

GRUs simplify LSTM by combining cell and hidden states into a single vector $h_t$ using two gates: Reset ($r_t$) and Update ($z_t$).

Property GRU LSTM
Gates 2 (Reset, Update) 3 (Forget, Input, Output)
State Vectors 1 ($h_t$) 2 ($C_t, h_t$)
Parameter Count $3 \times (m \cdot d + m^2 + m)$ $4 \times (m \cdot d + m^2 + m)$

6. Worked Numerical Example & Final Quiz

Fully Solved GRU Numerical

Given: $x_t = 1.0, h_{t-1} = 0.5$, Reset params ($W_r=0.2, U_r=0.5, b_r=0.0$), Update params ($W_z=0.8, U_z=-0.1, b_z=0.1$), Candidate params ($W_h=0.5, U_h=0.9, b_h=-0.2$).

  • Reset Gate: $r_t = \sigma(0.2(1) + 0.5(0.5) + 0) = \sigma(0.45) \approx 0.6107$
  • Update Gate: $z_t = \sigma(0.8(1) - 0.1(0.5) + 0.1) = \sigma(0.85) \approx 0.7006$
  • Gated Memory: $r_t \odot h_{t-1} = 0.6107 \times 0.5 = 0.3054$
  • Candidate: $\tilde{h}_t = \tanh(0.5(1) + 0.9(0.3054) - 0.2) = \tanh(0.5748) \approx 0.5188$
  • Final Output: $h_t = (1 - 0.7006)(0.5) + 0.7006(0.5188) = 0.1497 + 0.3635 = 0.5132$
