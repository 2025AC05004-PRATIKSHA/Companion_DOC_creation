01 · Module 6

CNN Design Patterns & Bottlenecks

Building deep convolutional networks requires systematic patterns rather than arbitrary layer arrangements: spatial reduction, channel expansion, residual shortcuts, and $1\times 1$ bottlenecks.

Everyday picture: Express Lanes & Compressed Pipes. A bottleneck is like a narrow funnel that squashes a wide pipe of data down to a smaller stream before processing, saving huge energy. A skip connection is like an express highway running parallel to local roads: if local traffic gets jammed (vanishing gradients), signals take the express lane.

Key Design Patterns

  • Pattern 1: Spatial Reduction + Channel Expansion. As spatial resolution decreases ($32\times32 \to 14\times14 \to 5\times5$), feature channels increase ($3 \to 16 \to 64 \to 256$).
  • Pattern 2: Repetitive Modular Blocks. Stack uniform building blocks (e.g., VGG $3\times3$ blocks or ResNet blocks) to scale depth easily.
  • Pattern 3: Residual / Skip Connections. Learn $y = F(x) + x$. The identity shortcut $x$ allows gradients to flow backwards without decay.
  • Pattern 4: Bottleneck Designs. Use $1\times1$ convs to compress channel depth before expensive $3\times3$ convs, then expand back ($8\times$ parameter reduction).
  • Pattern 5: Multi-Scale Extraction. Inception modules process inputs at parallel filter scales ($1\times1, 3\times3, 5\times5$).

Transfer Learning Strategy Framework

High Domain Similarity

Small Dataset: Freeze CNN backbone, train linear top classifier.
Large Dataset: Fine-tune all layers with a small learning rate.

Low Domain Similarity

Small Dataset: Freeze early low-level layers, train higher layers + head.
Large Dataset: Train complete network from scratch or fine-tune fully.

03 · Module 7

Sequence Modeling: Autoregressive vs Latent Variable

Standard feedforward networks fail on sequence data because inputs vary in length and lack temporal memory. Sequence models compress history into state variables.

Analogy first: Weather Forecasting. An autoregressive model predicts tomorrow's weather strictly by looking at today's temperature ($T_{t+1} = \alpha T_t + \beta$). A latent variable model keeps a running memory summary $h_t$ of the entire week's trend.
$$\text{Autoregressive (First-order Markov): } x_t = P(x_t \mid x_{t-1})$$ $$\text{Latent Variable Model (RNN): } h_t = g(h_{t-1}, x_t), \quad \hat{y}_t = f(h_t)$$

04 · Module 7

Vanilla Recurrent Neural Network (RNN)

An RNN updates its internal hidden state $h_t$ at each time step using parameter-shared matrices $W_{hh}, W_{hx}, W_{ho}$.

$$h_t = \tanh(W_{hh} h_{t-1} + W_{hx} x_t + b_h), \quad o_t = W_{ho} h_t + b_o$$
Parameter Counting Formula: Total Params = $h \cdot d + h^2 + h + V \cdot h + V$. For $d=100, h=256, V=10,000$, Total = $25,600 + 65,536 + 256 + 2,560,000 + 10,000 = 2,661,392$ parameters (~2.66M).

05 · Module 7

BPTT & The Vanishing Gradient Problem

Backpropagation Through Time unrolls the RNN graph. Multiplying by $W_{hh}^T \text{diag}(\phi')$ repeatedly across $T$ steps causes gradients to vanish or explode exponentially.

Gradient Decay Equation: $\frac{\partial L_T}{\partial h_k} = \frac{\partial L_T}{\partial h_T} \prod_{j=k+1}^T \text{diag}(\phi'(z_j)) W_{hh}^T$. If $\lambda_{\max} \cdot |\phi'| = 0.4$, after 20 steps $(0.4)^{20} \approx 10^{-8}$.

06 · Module 7

Gated Recurrent Unit (GRU)

GRU solves vanishing gradients using Reset ($r_t$) and Update ($z_t$) gates to create additive linear gradient highways.

$$r_t = \sigma(W_r x_t + U_r h_{t-1} + b_r), \quad z_t = \sigma(W_z x_t + U_z h_{t-1} + b_z)$$ $$\tilde{h}_t = \tanh(W_h x_t + U_h (r_t \odot h_{t-1}) + b_h)$$ $$h_t = z_t \odot h_{t-1} + (1 - z_t) \odot \tilde{h}_t$$

07 · Module 7

Long Short-Term Memory (LSTM)

LSTM separates long-term cell state memory $c_t$ from short-term hidden output $h_t$ using three dedicated gates: Forget ($f_t$), Input ($i_t$), and Output ($o_t$).

$$f_t = \sigma(W_f x_t + U_f h_{t-1} + b_f), \quad i_t = \sigma(W_i x_t + U_i h_{t-1} + b_i)$$ $$\tilde{c}_t = \tanh(W_c x_t + U_c h_{t-1} + b_c), \quad c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$$ $$o_t = \sigma(W_o x_t + U_o h_{t-1} + b_o), \quad h_t = o_t \odot \tanh(c_t)$$

POCKET CARD: Session 9 Key Formulas & Takeaways
  • Bottleneck Convs: $1\times 1$ convs reduce channel depth before expensive $3\times 3$ ops (~8x parameter reduction).
  • Residual Convs: $y = F(x) + x$ creates express identity highways for uninhibited gradient backpropagation.
  • Vanilla RNN: $h_t = \tanh(W_{hh} h_{t-1} + W_{hx} x_t + b_h)$. Recurrent Params = $hd + h^2 + h$. Vanishes as $(W_{hh}^T \phi')^k$.
  • GRU (2 Gates): Reset $r_t$, Update $z_t$, State $h_t = z_t \odot h_{t-1} + (1-z_t) \odot \tilde{h}_t$. Params = $3(hd + h^2 + h)$.
  • LSTM (3 Gates): Forget $f_t$, Input $i_t$, Output $o_t$. Cell update $c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$, Output $h_t = o_t \odot \tanh(c_t)$. Params = $4(hd + h^2 + h)$.
