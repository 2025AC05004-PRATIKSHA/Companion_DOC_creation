01 · Artificial Neurons

The Perceptron and the XOR Problem

The perceptron is the simplest artificial neuron. It multiplies features by weights, adds a bias, and checks if the total score crosses a threshold.

Analogy first. A single perceptron acts like a security gate with a rigid threshold. If the weighted sum of credentials meets the bar, the gate opens; otherwise, it stays shut. This creates a single straight boundary line in the feature space.
$$ z = w_1 x_1 + w_2 x_2 + b, \quad y = \begin{cases} 1 & \text{if } z \ge 0 \\ 0 & \text{if } z < 0 \end{cases} $$

02 · Continuous Prediction

Linear Regression with Identity Activation

Linear regression predicts continuous real values using an identity activation function \(f(z) = z\) and optimizes weights via gradient descent on squared error loss.

$$ \hat{y} = w_1 x_1 + w_2 x_2 + b, \quad L(y, \hat{y}) = \frac{1}{2}(y - \hat{y})^2 $$

03 · Binary Classification

Logistic Regression and Sigmoid Activation

To map real-valued scores into valid probabilities \((0,1)\), logistic regression applies the sigmoid function \(\sigma(z)\) and minimizes binary cross-entropy loss.

$$ \hat{y} = \sigma(z) = \frac{1}{1 + e^{-z}}, \quad L(y, \hat{y}) = -[y \log \hat{y} + (1-y)\log(1-\hat{y})] $$

⚡ Sigmoid & Probability Mapper

Slide score \(z\) or weight parameters to see how sigmoid squashes the value into a probability \(P(y=1)\).

04 · Multi-Class Classification

Softmax Activation and Normalized Probabilities

When classifying into \(K > 2\) classes, Softmax converts a vector of raw real-valued scores (logits) into a sum-to-one probability distribution.

$$ \hat{y}_k = \frac{e^{z_k}}{\sum_{j=1}^K e^{z_j}}, \quad L(\mathbf{y}, \hat{\mathbf{y}}) = -\sum_{k=1}^K y_k \log \hat{y}_k $$

05 · Deep Feed-Forward Networks

Layer-wise Computations and Depth

Deep Feed-Forward Neural Networks (DFNN) stack multiple hidden layers with non-linear activations to learn hierarchical feature representations.

$$ \mathbf{z}^{(l)} = \mathbf{W}^{(l)}\mathbf{a}^{(l-1)} + \mathbf{b}^{(l)}, \quad \mathbf{a}^{(l)} = f(\mathbf{z}^{(l)}) $$

⚡ 2-Layer Neural Network Forward Propagation Lab

Change input values and observe the forward pass step-by-step through hidden layer activations (ReLU) to the final output.

06 · Convolutional Neural Networks

Convolution, Padding, Stride, and Max Pooling

CNNs preserve spatial structures in images using local receptive fields, parameter sharing, and downsampling pooling layers.

$$ \text{Output Shape } O = \left\lfloor \frac{N + 2P - K}{S} \right\rfloor + 1 $$

⚡ Interactive Convolution & Max Pooling Visualizer

Click Step Filter to slide the $3 \times 3$ filter across the input grid and perform convolution, ReLU, and max pooling.

07 · Wrap Up

Key Takeaways

1 · Neurons & Gates

Single perceptrons handle linear decision boundaries (AND/OR), while multi-layer networks solve non-linear problems like XOR.

2 · Classification Loss

Sigmoid handles binary classification with BCE loss; Softmax converts multi-class logits into probability distributions.

3 · CNN Efficiency

Convolutional filters share parameters across spatial locations, while pooling layers reduce spatial dimensions with zero parameters.
